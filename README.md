# Cart Canyon

A single-page **product showcase** built with HTML and Tailwind CSS (CDN). Responsive product card with pricing, features, and CTA.

## Features

- Mobile-first layout with desktop background art
- Tailwind utility styling + custom fonts
- Product image, feature list, price, Add to Cart CTA

## Tech

HTML5 · Tailwind CSS (CDN) · Google Fonts

## Run

```bash
git clone https://github.com/bugship/cart-canyon.git
cd cart-canyon
open index.html
```
